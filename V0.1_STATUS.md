# The LostCompass Project — V0.1 Status

Draft Status: Human review required.

## Current project status

The LostCompass Project V0.1 is an early-stage brand website and local drafting tool for outdoor stories, forgotten places, apparel previews, and future conservation-oriented content.

The site is functional as a local Vite/React website. It is not ready for a public production launch without review, authentication decisions, content verification, policies, and deployment hardening.

- Brand website foundation
- Leave It Wild tagline
- Main navigation
- Outdoor premium visual style
- Apparel preview/catalog area
- Collection pages
- Product preview pages
- Coming Soon mode
- No cart
- No checkout
- No payment
- Story listing
- Story detail pages
- Local Story Manager / Article Admin
- Add/Edit/Save/Delete/Preview workflow
- Manual image path support
- Research notes/checklist support

## What is local-only

- Story Manager / Article Admin

## What is not ready for public deployment

- Admin route has no authentication
- Story Manager uses browser localStorage only
- No backend CMS exists yet
- No file upload system exists yet
- No privacy/terms/returns policy set exists yet
- No real checkout, cart, payment, or apparel store integration exists yet
- Lost Cove facts and sources are not verified yet

## Known limitations

- LocalStorage data is browser-specific and can be cleared by the browser.
- LocalStorage data is not automatically committed back to source files.
- Image paths must be typed manually.
- Missing image files may render as blank image areas.
- Story Manager is not multi-user.
- Story Manager has no access control.
- The Lost Cove draft intentionally avoids unsupported historical claims.

## Do-not-deploy warnings

- Do not deploy `#/admin/stories` publicly without authentication.
- Do not publish draft stories without human review.
- Do not claim conservation impact before it exists and is documented.
- Do not add checkout/cart/payment until store, policy, tax, and fulfillment details are ready.
- Do not use the user's real name in public-facing LostCompass content.
